# Trust Risk Ladder

## Risk Levels

MEMBRA uses a tiered risk ladder to categorize inventory and transactions. Each level has specific requirements, protections, and pricing implications.

### Level 0: Zero Risk (Storage Only)
**Categories**: Shelf space, closet space, garage space, fridge space
**Requirements**: None
**Verification**: Basic account verification
**Protection**: None required
**Proof**: Not required
**Insurance**: Not required
**Pricing**: Lowest MUP

### Level 1: Low Risk
**Categories**: Tools, small appliances, furniture, sealed consumables
**Requirements**: 
- Email verified
- Phone verified
- Basic profile complete
**Verification**: Photo ID verification
**Protection**: Host can require deposit
**Proof**: Photo proof of return recommended
**Insurance**: Optional, host can opt-in
**Pricing**: Standard MUP

### Level 2: Medium Risk
**Categories**: Larger appliances, electronics, specialty equipment
**Requirements**:
- Level 1 requirements
- 3+ successful transactions
- Trust score > 0.7
**Verification**: Enhanced verification (address, additional ID)
**Protection**: Deposit required (10-20% of asset value)
**Proof**: Photo proof required
**Insurance**: Required (platform provides)
**Pricing**: MUP + risk premium

### Level 3: High Risk
**Categories**: High-value items, specialized equipment, access to sensitive areas
**Requirements**:
- Level 2 requirements
- 10+ successful transactions
- Trust score > 0.85
- Background check (optional but recommended)
**Verification**: Full verification including video verification
**Protection**: Deposit required (25-50% of asset value)
**Proof**: Photo + GPS proof required
**Insurance**: Required with higher coverage
**Pricing**: MUP + significant risk premium

### Level 4: Prohibited (MVP)
**Categories**: Bedrooms, unattended home access, hygiene-sensitive goods, medical items, weapons, controlled substances, adult access, financial services, childcare, unsupervised personal-care services
**Requirements**: Not allowed in MVP
**Verification**: N/A
**Protection**: N/A
**Proof**: N/A
**Insurance**: N/A
**Pricing**: N/A

## Trust Score Calculation

### Base Score (0-1.0)
- Account age: 0-0.2 (older = higher)
- Verification level: 0-0.3 (higher verification = higher)
- Transaction count: 0-0.2 (more transactions = higher)
- Success rate: 0-0.2 (higher = higher)
- Response time: 0-0.1 (faster = higher)

### Penalties
- Cancelled transactions: -0.05 per cancellation
- Dispute lost: -0.1 per lost dispute
- Late return: -0.05 per late return
- Damage incident: -0.2 per incident

### Bonuses
- Hero fulfillment: +0.05 per successful fulfillment
- 5-star reviews: +0.01 per 5-star review
- Consistent availability: +0.05 per month
- Verified host: +0.1

### Minimum Score
- 0.0 (new users start at 0.5)
- 0.2 (minimum to transact)
- 0.7 (required for Level 2 items)
- 0.85 (required for Level 3 items)

## Verification Tiers

### Tier 1: Basic
- Email verification
- Phone verification
- Profile photo
- Basic address

### Tier 2: Enhanced
- Tier 1 requirements
- Government ID verification
- Selfie verification
- Proof of address (utility bill, bank statement)

### Tier 3: Full
- Tier 2 requirements
- Video verification
- Social media verification
- Employment verification (optional)
- Background check (optional)

## Protection Mechanisms

### Deposits
- Host can require deposit for Level 2+ items
- Deposit held in escrow until return verified
- Deposit released if no damage
- Deposit used to cover damage if applicable
- Deposit refund within 24-48 hours

### Insurance
- Platform provides insurance for Level 2+ items
- Insurance covers: damage, theft, loss
- Insurance premium: 5-10% of transaction value
- Claims process: photo evidence + host testimony
- Claim resolution: 3-7 days

### Proof Requirements
- Photo proof: before/after photos of item
- GPS proof: location verification for pickup/delivery
- Time-stamp: verification of access duration
- Digital signature: acknowledgment of condition
- Video proof: for high-value items (optional)

### Dispute Resolution
- Automated review for minor disputes
- Human review for major disputes
- Evidence-based decision making
- Appeal process available
- Resolution within 3-7 days

## Access Control

### Supervised Access
- Host present during entire access period
- Recommended for Level 2+ items
- Higher trust required
- Lower insurance premium

### Unsupervised Access
- Host not present during access
- Requires Level 2+ verification
- Requires higher trust score
- Requires deposit
- Higher insurance premium

### Remote Access
- No physical access required
- Examples: storage space, pickup/dropoff
- Lower risk
- Lower insurance premium
- No deposit required

## Reputation System

### Host Reputation
- Response rate
- Response time
- Cancellation rate
- Item condition accuracy
- Communication quality
- Fulfillment reliability

### Requester Reputation
- On-time pickup
- On-time return
- Item care
- Communication
- Payment reliability
- Dispute history

### Hero Reputation
- On-time pickup
- On-time delivery
- Item handling
- Communication
- Problem resolution
- Customer satisfaction

### Reputation Decay
- Reputation decays over time if inactive
- 6 months inactivity: -10% reputation
- 12 months inactivity: -25% reputation
- Reactivation requires rebuilding reputation

## Risk Mitigation Strategies

### For Hosts
- Start with Level 0-1 items
- Require deposits for new requesters
- Use heroes for fulfillment
- Require photo proof
- Check requester reputation
- Set appropriate access rules

### For Requesters
- Build reputation with low-risk items first
- Provide good communication
- Return items on time
- Take photos for proof
- Report issues promptly
- Leave honest reviews

### For Heroes
- Start with low-risk pickups
- Provide good communication
- Handle items with care
- Take photos at pickup/delivery
- Report issues promptly
- Build reputation over time

## Fraud Prevention

### Detection
- Unusual transaction patterns
- Multiple disputes from same user
- Rapid cancellation rate
- Suspicious communication
- Location inconsistencies

### Prevention
- Rate limiting on new users
- Minimum time between transactions
- Maximum transaction value for new users
- Geographic restrictions
- Device fingerprinting

### Response
- Account suspension
- Transaction reversal
- Legal action for fraud
- Blacklisting from platform
