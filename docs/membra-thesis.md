# MEMBRA Thesis

## Core Positioning

MEMBRA is the inventory, access, trust, and fulfillment layer for household-to-market conversion.

That framing makes the household behave like a commercial node. Every couch, shelf, tool, outlet, errand, storage corner, appliance, and skill becomes a permissioned SKU. The host does not need to manually build a store. MEMBRA scans the room, structures the inventory, prices the unit, verifies access rules, and routes demand.

## Why Now

AI vision can now detect household assets. LLMs can translate casual user intent into structured requests. Payments and identity rails already exist. Local commerce is fragmented across Facebook Marketplace, Craigslist, storage apps, gig apps, and delivery platforms. MEMBRA combines those into a permissioned, AI-mediated household inventory network.

## Product Architecture

Intent → Inventory → Assetization → Fractionalization → Listing → Access → Fulfillment → Proof → Settlement → Reputation → Replenishment

That loop is the right backbone because it gives MEMBRA more depth than a rental marketplace. It becomes a local commerce operating system.

## MVP Strategy

Start with low-risk, high-frequency, easy-proof SKUs:

- Storage shelf space
- Closet space
- Tool access
- Vacuum rental
- Folding chair rental
- Charging/workspace access
- Local drop-off errands
- Sealed household consumables
- Small appliance access

Avoid high-liability categories early:
- Bedrooms
- Unattended home access
- Hygiene-sensitive goods
- Medical items
- Weapons
- Controlled substances
- Adult access
- Financial services
- Childcare
- Unsupervised personal-care services

## Initial Wedges

### Overflow Inventory Hosting

Hosts list unused shelf, closet, garage, fridge, or storage space. It is easier to trust than borrowing a stranger's couch or entering someone's home for broad access. It also maps naturally to the dashboard: shelf space, closet space, corner storage, rentable inventory, approval flow, trust score, and node yield.

### Micro-Utility Rentals

Vacuum for 20 minutes. Drill for one hour. Ring light for one shoot. Folding chairs for an evening. Charger access for 30 minutes. These are simple, understandable, hyperlocal SKUs.

### Household Fulfillment Nodes

Hosts earn by storing, handing off, delivering, or meeting halfway. That gives MEMBRA a DoorDash/Amazon-like logistics angle without needing warehouses.

## User Roles

- **Host**: Owns assets, space, services, or local availability
- **Requester**: Needs access to an object, space, service, or errand
- **Hero**: Fulfills delivery, pickup, inspection, setup, or handoff
- **House**: Physical household node with inventory, trust score, availability, and access rules

The Hero/House/Alpha Hub model avoids making the resident do everything. A resident can monetize; a local hero can fulfill.

## Monetization Stack

- Transaction fee on rentals/access
- Subscription for power hosts
- Verification fee for trusted inventory nodes
- Premium placement for local SKUs
- Insurance/protection margin
- Fulfillment margin on delivery or handoff
- B2B/API access for property managers, dorms, co-living operators, local merchants, and apartment buildings

## Product Flow

Scan your room → Approve detected inventory → Set what is rentable → Receive local requests → Hand off or fulfill → Get paid

## Demo Flow

A phone scans a living room.

MEMBRA detects: couch seat, vacuum, shelf space, ring light, chair, boxes, charger, extension cord.

Each item becomes a card with match confidence, rent mode, space mode, risk rating, suggested price, and approval button.

The host approves five safe SKUs.

A requester asks: "Need a vacuum near me for 20 minutes."

MEMBRA matches the nearest verified host.

The requester pays.

The host or hero fulfills.

Photo proof confirms return.

Settlement and reputation update.
