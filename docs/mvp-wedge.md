# MEMBRA MVP Wedges

## Wedge Strategy

MEMBRA enters the market through three sequential wedges, each building on the previous and increasing complexity while maintaining low risk and easy proof.

MEMBRA starts with the lowest-risk, highest-frequency household utility. Storage and simple tool access have:
- Minimal liability
- Easy proof (before/after photos)
- Clear pricing (MUP calculation)
- High repeatability
- Low fulfillment friction

These wedges establish the field grammar, trust scoring, and settlement patterns before expanding to higher-risk categories.

## Wedge 1: Overflow Inventory Hosting

### Description

Convert unused household storage capacity into searchable, priced, and permissioned storage SKUs.

### Categories

- Shelf space (3ft, 5ft, custom)
- Closet space (5ft, full closet, walk-in)
- Garage space (parking spot, storage area, workbench access)
- Fridge shelf space (single shelf, full door, dedicated section)
- Small storage capacity (under-bed, attic crawl space, basement corner)

### Why This Wedge?

1. **Low Risk**: Storage is low-liability, low-damage, low-theft risk
2. **Easy Proof**: Photos before/after, simple inventory lists
3. **High Demand**: Urban dwellers always need storage
4. **Clear Pricing**: $/cubic-foot/month is intuitive
5. **No Entry Required**: Most storage is on-premise use, self-service
6. **Repeatable**: Storage needs are recurring (monthly billing)

### Access Modes

- On-Premise Use: Requester uses space on host's property
- Self-Service: Requester manages their own access
- No Home Entry: Host provides access code or key

### Fulfillment Modes

- Self-Service: Requester accesses independently
- Host Handoff: Host provides access at scheduled time
- Key Exchange: Physical key or code exchange

### MUP Calculation

Base: $0.00 (no depreciation)
Setup overhead: $2.50–$5.00/month
Risk premium: $0.00 (low risk)
Market adjustment: $0.50–$2.00/month
Platform margin: 15–25%

### Example SKU

- **Item**: Closet Space (5ft)
- **Unit Type**: cubic-foot/month
- **MUP**: $12.00
- **Suggested Price**: $15.00/month
- **Access Mode**: On-Premise Use
- **Fulfillment Mode**: Self-Service
- **Risk Grade**: Low
- **Proof Required**: None (self-service)

## Wedge 2: Micro-Utility Rentals

### Description

Convert household tools and appliances into fractional access SKUs for short-term use.

### Categories

- Vacuum access (20-minute use, hourly use)
- Drill access (hourly use, daily use)
- Ring light access (hourly use, daily use)
- Folding chair access (hourly seating)
- Charger/workspace access (hourly charging, desk use)

### Why This Wedge?

1. **Medium Risk**: Tools have some damage/theft risk but are manageable
2. **Easy Proof**: Return photo, condition check
3. **High Frequency**: Tools are frequently needed but rarely owned
4. **Clear Pricing**: $/hour or $/day is intuitive
5. **No Entry Required**: Door handoff for most items
6. **Repeatable**: Project-based recurring needs

### Access Modes

- Door Handoff: Item handed off at door
- No Entry: Requester never enters home
- Meet Halfway: Neutral location exchange

### Fulfillment Modes

- Host Handoff: Host provides item at scheduled time
- Self-Service: Requester picks up from accessible location
- Key Exchange: Access to storage locker

### MUP Calculation

Base: Hourly depreciation + setup overhead
Risk premium: 0.05–0.09/hour
Market adjustment: 0.25–2.00/hour
Platform margin: 15–25%

### Example SKU

- **Item**: Vacuum Cleaner
- **Unit Type**: 20-minute use
- **MUP**: $5.00
- **Suggested Price**: $7.50/use
- **Access Mode**: Door Handoff
- **Fulfillment Mode**: Host Handoff
- **Risk Grade**: Low-Medium
- **Proof Required**: Return photo

## Wedge 3: Household Fulfillment Nodes

### Description

Convert household availability and local presence into fulfillment service SKUs.

### Categories

- Handoff (package handoff, key exchange)
- Pickup (local pickup coordination)
- Local delivery (neighborhood delivery)
- Inspection (item inspection before/after use)
- Setup (equipment setup assistance)
- Return (item return coordination)
- Replenishment (supply restocking)

### Why This Wedge?

1. **Low Physical Risk**: Services have low asset risk
2. **Proof-Based**: Photos, timestamps, location verification
3. **High Demand**: Last-mile fulfillment is expensive
4. **Clear Pricing**: $/service or $/hour is intuitive
5. **Flexible**: Can be combined with other wedges
6. **Repeatable**: Recurring fulfillment needs

### Access Modes

- Door Handoff: Service at host's door
- On-Site: Service on host's property
- Off-Site: Service at neutral location

### Fulfillment Modes

- Host Performs: Host provides the service
- Hero Performs: Third-party hero provides service
- Self-Service: Requester performs with guidance

### MUP Calculation

Base: Time-based ($/hour) or service-based ($/service)
Setup overhead: Scheduling and coordination
Risk premium: Low (service-based)
Market adjustment: Local market rates
Platform margin: 20–30%

### Example SKU

- **Item**: Package Handoff
- **Unit Type**: per package
- **MUP**: $2.00
- **Suggested Price**: $3.00/package
- **Access Mode**: Door Handoff
- **Fulfillment Mode**: Host Performs
- **Risk Grade**: Low
- **Proof Required**: Photo of handoff

## Wedge Progression

### Phase 1: Wedge 1 Only
- Focus on overflow inventory hosting
- Establish storage SKU patterns
- Build trust scoring for storage
- Prove monthly recurring revenue

### Phase 2: Wedge 1 + Wedge 2
- Add micro-utility rentals
- Establish tool/appliance SKU patterns
- Build return photo verification
- Prove fractional access model

### Phase 3: Wedge 1 + Wedge 2 + Wedge 3
- Add household fulfillment nodes
- Establish service SKU patterns
- Build hero network for fulfillment
- Prove last-mile value

## Wedge Success Criteria

Each wedge must achieve:

1. **100+ SKUs listed** in the category
2. **50+ completed transactions** with positive ratings
3. **<5% dispute rate** with clear resolution
4. **Repeat usage rate >30%** among users
5. **Average rating >4.5/5** for both hosts and requesters
6. **Proof verification rate >95%** for completed transactions

Only when a wedge meets these criteria does MEMBRA expand to the next wedge.
