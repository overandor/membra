# MEMBRA Product Doctrine

## One-Sentence Doctrine

MEMBRA is the AI operating system that turns private household utility into verified, fractional, permissioned local commerce.

## Not a Marketplace First

MEMBRA is not "people renting their stuff."

MEMBRA is the inventory, access, trust, proof, fulfillment, and settlement layer for household-to-market conversion.

## Core Loop

Intent → Inventory → Assetization → Fractionalization → Listing → Access → Fulfillment → Proof → Settlement → Reputation → Replenishment

## Initial Wedge

Overflow Inventory Hosting:
- Shelf space
- Closet space
- Garage space
- Fridge shelf space
- Small storage capacity

## Second Wedge

Micro-Utility Rentals:
- Vacuum access
- Drill access
- Ring light access
- Folding chair access
- Charger/workspace access

## Third Wedge

Household Fulfillment Nodes:
- Handoff
- Pickup
- Local delivery
- Inspection
- Setup
- Return
- Replenishment

## User Roles

- **Host**: Owns assets, space, services, or local availability
- **Requester**: Needs access to an object, space, service, or errand
- **Hero**: Fulfills delivery, pickup, inspection, setup, return, or handoff
- **House**: Physical household node with inventory, trust score, availability, and access rules

## Proprietary Primitives

- Inventory Node
- SKU Verification
- FractionOS
- AccessOS
- TrustOS
- OracleOS
- LedgerOS
- MUP
- MembraIndexRecord
- Trust-Adjusted Liquidity
- Household Utility Index

## Demo Doctrine

The first product demo should show one tight loop:

Scan room → detect assets → approve safe SKUs → price units → match request → dry-run fulfillment → proof → settlement log → export investor summary

## Risk Doctrine

MEMBRA starts with low-risk, easy-proof household utility.

MEMBRA avoids high-liability categories until trust, insurance, verification, and compliance rails mature.

## Final Tagline

MEMBRA turns every home into a verified inventory node.

## Technical Tagline

MEMBRA is an AI inventory graph for private household assets, converting physical utility into verified, priced, permissioned, and settleable local SKUs.
