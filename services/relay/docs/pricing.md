# MEMBRA Relay Pricing and Payment Splits

## Distance-Based Pricing

| Distance | Price Range |
|----------|--------------|
| Pickup only | $0 |
| Meet halfway | $2–$5 |
| Under 0.5 mile delivery | $4–$7 |
| 0.5–2 miles | $7–$12 |
| 2–5 miles | $12–$25 |
| Cross-city | Quote required |

## Payment Splits

### Local Delivery (Under 2 miles)
```
User pays: $18
- Inventory Hero: $7 (39%)
- Relay Agent: $6 (33%)
- Alpha Hub: $2 (11%)
- User cashback: $1 (6%)
- MEMBRA fee: $2 (11%)
```

## Platform Fees

MEMBRA platform fees cover:
- Payment processing
- Insurance pool
- Dispatch AI
- Trust and verification
- Customer support
- Network infrastructure

Fee structure:
- Standard: 11–20% of total price
- Enterprise partners: Negotiated rates
- High-volume agents: Reduced rates (10–15%)
