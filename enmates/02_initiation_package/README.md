# Initiation Package (IP)

This directory contains Initiation Package components for the EnMaTeS architecture.

## Components

- **SG (Semantic Graph)**: Persistent project memory stored in semantic graph
- **SDA (Source Documents/Artifacts)**: Source documents and artifacts for the project
- **SP (Starting Prompt)**: Initial prompt for agent initialization
- **UM (Operator Manual)**: Manual for operator guidance

## Assembly Rule

Do not operate from loose chat memory. Operate from SI + IP.

SI = SMF + FPM + FPS + PIC
IP = SG + SDA + SP + UM

ChatConfig declares exact versions to load.
