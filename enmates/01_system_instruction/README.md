# System Instruction (SI)

This directory contains System Instruction components for the EnMaTeS architecture.

## Components

- **SMF (Semantic Graph Schema)**: Defines the structure of the semantic graph
- **FPM (Operating Mode)**: Specifies the operating mode for agents
- **FPS (Agent Role/Specialization)**: Defines agent roles and specializations
- **PIC (Mission, Purpose, Constraints)**: Specifies mission, purpose, and constraints

## Assembly Rule

Do not operate from loose chat memory. Operate from SI + IP.

SI = SMF + FPM + FPS + PIC
IP = SG + SDA + SP + UM

ChatConfig declares exact versions to load.
