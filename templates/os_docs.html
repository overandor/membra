Developer Docs

Root command center for developing the MEMBRA repo family as one operating system.

Primary rule

Develop against modules/registry.json. Each module must keep a MEMBRA_MODULE.md contract.

Bootstrap workspace

python scripts/bootstrap_modules.py
python scripts/status_modules.py

Primary deployable

Membra_kpi is the first full Replit deployable product. It owns the photo/data → SKU → KPI → ProofBook → draft → owner-confirmed marketplace → payout eligibility loop.

APIs

GET /api/health
GET /api/registry
GET /api/modules
GET /api/modules/{module_id}
GET /api/replit-plan

Boundary

MEMBRA records proof, listings, reports, and payout eligibility. MEMBRA does not custody funds. External rails settle money.
